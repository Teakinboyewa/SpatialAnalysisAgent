# GIBD service

Keys containing `gibd-services` route requests through GIBD. Visit the [service website](https://www.gibd.online/) for registration, key generation, and current account terms.

See [Configuration and data handling](docs/configuration.md) for plugin setup, request data, and feedback behavior. Earlier documentation described a daily quota offer ending December 31, 2025; that offer is historical and does not establish current access limits.
